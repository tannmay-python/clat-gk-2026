# Data contract

Every month is one JSON file at `data/months/<YYYY-MM>.json`. Static GK sections live at `data/static/<slug>.json`. Both use the same shape.

```jsonc
{
  "id": "2026-01",                  // month id, or static slug like "polity"
  "kind": "current",                // "current" | "static"
  "label": "January 2026",
  "blurb": "2-3 sentences on what dominated the month. Voice rules apply.",
  "topics": [ /* Topic */ ],
  "passages": [ /* Passage */ ]
}
```

## Topic

```jsonc
{
  "id": "2026-01-us-venezuela",     // month-slug, globally unique, kebab-case
  "rank": 1,                         // 1 = most exam-relevant in this month
  "depth": "deep",                   // deep | medium | brief
  "importance": 5,                   // 1-5, how likely CLAT touches it
  "title": "US strikes on Venezuela and the return of the Monroe Doctrine",
  "date": "2026-01-14",              // best single date, ISO
  "category": "International Relations",
  "tags": ["Venezuela", "USA", "Monroe Doctrine"],
  "hook": "One sentence. What happened and why an exam would care.",
  "story": "Markdown. Paragraphs separated by \\n\\n. Bold sparingly. No headings above ###.",
  "facts": [                         // exam-ready factoids, the stuff MCQs are built from
    { "k": "Monroe Doctrine year", "v": "1823" },
    { "k": "Author", "v": "President James Monroe, in his seventh annual message to Congress" }
  ],
  "timeline": [                      // optional, deep topics only
    { "when": "1823", "what": "Monroe Doctrine announced" }
  ],
  "why": "2-4 sentences on how CLAT would actually test this — passage angle, likely trap.",
  "map": { "nodes": [ /* MapNode */ ] },
  "sources": ["https://..."]
}
```

Word budgets by depth. Stick to them.

| depth  | story words | map nodes | facts |
|--------|-------------|-----------|-------|
| deep   | 550–850     | 18–30     | 8–14  |
| medium | 250–400     | 8–14      | 5–8   |
| brief  | 120–200     | 4–7       | 3–5   |

## MapNode

The map is a radial tree. Every node hangs off `"root"` or off another node. Importance falls as you move outward, and the UI dims by tier, so put the corollaries an examiner would actually ask about in tier 1.

```jsonc
{
  "id": "monroe",
  "parent": "root",                 // "root" or another node id in this map
  "tier": 1,                        // 1 = direct, high-yield. 2 = second order. 3 = flavour.
  "label": "Monroe Doctrine (1823)",
  "kind": "event",                  // person | org | event | concept | place | law | book | award | term
  "rel": "doctrine invoked",        // edge label, 1-3 words, lowercase
  "note": "One or two sentences. A fact, not a summary of the label.",
  "topicRef": "2025-11-monroe-recap", // optional: id of another topic in the corpus
  "staticRef": "polity#emergency"     // optional: static section anchor
}
```

Rules for maps:
- Node count by depth table above. Tier 1 gets 4–6 nodes; the rest spread across tiers 2 and 3.
- Every node's `note` must carry a fact that could be asked. "Sam Altman" is useless; "Sam Altman, OpenAI CEO, was fired and reinstated over five days in November 2023" is a question.
- Mix the kinds. A good map has a person, an organisation, a historical precedent, a legal or constitutional hook, and a number.
- Static GK hooks matter more than more news. If a current topic touches Article 356, put Article 356 on the map.

## Passage

CLAT format: a passage of 250–400 words, then 5 questions with 4 options each. Questions test inference and application, not recall of a stray noun. Roughly: one main-idea question, two inference questions, one "which of the following is true/false" fact check, one that needs outside static knowledge the passage only gestures at.

```jsonc
{
  "id": "2026-01-p1",
  "kind": "current",                // current | static
  "month": "2026-01",               // month id, or static slug
  "topicIds": ["2026-01-us-venezuela"],
  "category": "International Relations",
  "tags": ["Venezuela", "Monroe Doctrine"],
  "difficulty": 2,                  // 1 easy, 2 moderate, 3 hard
  "title": "Short label for the passage",
  "passage": "250-400 words. Written like a news-analysis extract, the way CLAT lifts from The Hindu or Indian Express. No bullet points.",
  "questions": [
    {
      "q": "Question text.",
      "options": ["A text", "B text", "C text", "D text"],
      "answer": 2,                  // 0-indexed
      "explain": "Why the right one is right and, where useful, why the tempting wrong one is wrong."
    }
  ]
}
```

Eight passages per month file. Twelve per static file.
